# 水墨主题 (Shuimo Theme)

> 点墨成渊映竹影，化筠为简蕴幽香。
> 指尖经纬裁风雨，且护明眸夜未央。

**水墨 Theme** 是一款根植于东方美学哲理的 VS Code 主题集合。摒弃了传统的高饱和度色彩堆砌，以「意象留白」与「长时护眼」为核心设计理念，为您打造一方沉静、清幽的代码书写天地。

---

## 🎨 主题意境 (The Themes)

### 墨韵 · 水墨丹青 (Ink Wash Light)

> 案上微寒展玉宣，毫端深浅化孤云。
> 丹青点染千行句，不惹红尘扰寸心。

以宣纸质感的淡雅色调为底，深浅墨色区分代码层级。仅在关键处点缀传统「丹青」之色，营造如观古画般的宁静体验。

### 翠微 · 竹林深处 (Bamboo Green)

> 幽篁斜抱半窗风，碎叶交筛落翠空。
> 敲罢繁星织夜雨，绿荫长护眼瞳中。

以青竹为底色，搭配浓墨与黛绿文字。精心调优的对比度，保证代码清晰的同时最大限度缓解眼部疲劳，适合长时间沉浸式开发。

## 🖼️ 沉浸体验 (Background Setup)

为达到极致的东方美学体验，建议搭配背景图片使用。由于 VS Code 原生限制，需要通过扩展来实现：

- 安装第三方扩展，例如 [Background](https://marketplace.visualstudio.com/items?itemName=Katsute.code-background)，具体使用方法自行AI
