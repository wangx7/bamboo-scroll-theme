# 水墨主题 (Shuimo Theme)

一款根植于东方美学的 VS Code 主题集合，以「意象留白」与「长时护眼」为核心设计理念。

---

## 主题

### 水墨·无争

> 五色墨里观云起，一池水中见天机。
> 朱砂不争春色早，只把锋芒隐砚池。

默认主题，以「墨为主，色为辅，计白当黑，惜墨如金」为哲学。**v2.6 生理学优化版**：所有色值经 WCAG 2.1 实测，为 8 小时连续编码调校。

| 角色 | 色名 | 色值 | 对比度 | 字体 |
|---|---|---|---|---|
| 画布背景 | 宣纸暖白 | `#F5F1DE` | — | — |
| 正文 / 变量 | 浓墨 | `#383A3D` | 10.1:1 | 常规 |
| 类型 / 类 / 命名空间 | 焦墨 | `#2C2E31` | 12.0:1 | 粗体 |
| 属性 / 参数 / 标点 / 运算符 | 淡墨 | `#475663` | 6.7:1 | 常规 / 斜体 |
| 行号 / Inlay / Ghost Text | 清墨 | `#5A5F66` | 5.7:1 | 常规 |
| 注释 | 水汽灰青 | `#566971` | 5.1:1 | 斜体 |
| 字符串 / 正则 | 潭水青 | `#1F6E5C` | 5.4:1 | 常规 |
| 函数 / 方法 / 链接 | 远水蓝 | `#3A6680` | 5.5:1 | 声明粗体 |
| 关键字 / 错误 / 当前焦点 | 朱砂 | `#8B402F` | 6.5:1 | 控制流粗体 |
| 数字 | 赭石 | `#80622E` | 5.0:1 | 常规 |
| 常量 / 装饰器 / 生命周期 | 紫毫 | `#6F5E8A` | 5.1:1 | 常规 / 斜体 |

**生理学设计要点（v2.6）：**

- 正文对比度由 `12.7:1` 降至 `10.1:1`，进入长时阅读舒适区（7~10:1），减少瞳孔频繁收缩导致的睫状肌疲劳。
- 朱砂饱和度 `54%→49%`，降低视网膜 L 锥细胞的持续刺激——「老朱砂经年氧化后的沉稳」。
- 注释对比度由 `4.4:1` 提升至 `5.1:1`，达到 WCAG AA，注释不再「吃力地看」。
- 全部 125 项静态语法 Token 对比度 `>= 4.5:1`（WCAG AA，含注释）。
- 选择区改为低饱和淡青灰晕染（`#3A668038`），减少「蓝色覆盖」造成的视觉打断。
- UI 纸面层次联动：侧边栏 `#F0ECDA`、活动栏 `#EAE5CC`、终端 `#F3F0DC`，色温一致（约 3400K 烛光色温）。

### 水墨·丹青

> 大千一墨化鸿蒙，万象森罗指掌中。
> 代码纵横经纬里，山河入眼夜朦胧。

以宣纸暖白 `#F6F5E1` 为底，全画布同色、无界融通。**v2.7 生理学与语义学优化版**：与无争 v2.6 同标调校，全部色值经 WCAG 2.1 实测。

| 角色 | 色名 | 色值 | 对比度 | 字体 |
|---|---|---|---|---|
| 正文 / 变量 | 浓墨 | `#383A3D` | 10.4:1 | 常规 |
| 类型 / 类 / 命名空间 | 焦墨 | `#2C2E31` | 12.4:1 | 粗体 |
| 标点 / 引用块 | 淡墨 | `#4A4F56` | 7.5:1 | 常规 / 斜体 |
| 行号 / this / 运算符 | 清墨 | `#5A5F66` | 5.7:1 | 常规 |
| 注释 | 水汽灰青 | `#51686E` | 5.4:1 | 斜体 |
| 字符串 / 正则 | 潭青 | `#1F7A85` | 4.6:1 | 常规 |
| 函数 / 方法 / 链接 | 远水蓝 | `#315D8C` | 6.2:1 | 常规 |
| 关键字 / 错误 | 朱砂 | `#9A3B26` | 6.3:1 | 粗体 |
| 数字 / 常量 | 赭石 | `#8A4B2F` | 6.1:1 | 常规 |
| 参数 / 属性名 | 赭沙 | `#6F6040` | 5.6:1 | 斜体 |
| 修饰符 / 装饰器 | 紫毫 | `#7A5B8C` | 5.2:1 | 常规 / 斜体 |
| 交互焦点 / 链接 | 远水蓝 | `#315D8C` | 6.2:1 | — |
| 新增 / 成功 / Diff 插入 | 松绿 | `#4C7548` | 4.8:1 | — |

**v2.7 生理学与语义学设计要点：**

- 正文对比度由 `12.8:1` 降至 `10.4:1`，进入长时阅读舒适区（7~10:1），与无争 v2.6 同标。
- 注释由松绿改为水汽灰青 `#51686E`：与 Git 新增 / 成功 / Diff 插入的松绿语义解耦（一色不兼两义），对比度 `4.8→5.4:1` 达 WCAG AA。
- 焦点框由朱砂改为远水蓝：交互焦点与错误红解耦，朱砂退守印章式强调（光标、徽标、活动标签顶线、面板激活）。
- 粗体层级重整：关键字全系加粗并与语义高亮对齐；`storage.type` 原语（int/string）与修饰符（public/private）去粗体，与类型名（粗体焦墨）拉开层级。
- 藤黄族统一：代码 token 藤黄 `#846616`（布尔 / 枚举成员 / 属性名 / 常量 / SQL 表名），UI 警告藤黄 `#8A6D1F`；符号图标（boolean/null/enumMember）与代码着色对齐。
- 终端 bright 8 级梯度拉开（绿 `#55834E` / 黄 `#97751F` / 青 `#26828E`），不再与 normal 混淆。
- 补齐 13 项缺失 UI 键：Unicode 高危字符高亮（原不可见）、远程状态栏指示、终端命令装饰、断点图标、面板激活指示、吸顶阴影、建议项选中前景、行号 dimmed 等。
- 全部 125 项静态语法 Token 达到 WCAG 2.1 AA（含注释在内均 `>= 4.5:1`），注释与正文可分辨 `1.93:1`。

### 水墨·竹韵

> 幽篁斜抱半窗风，碎叶交筛落翠空。

## 推荐搭配

水墨主题已为以下扩展预设配色，安装后即可获得一致的视觉体验。

### Error Lens

错误 / 警告 / 提示的行内高亮已与主题色板对齐：朱砂表错误、赭沙表警告、远水蓝表信息、淡墨表提示。无需额外配置。

### Better Comments

将以下配置复制到 `settings.json`，让注释按语义着色，与水墨色板保持一致：

```jsonc
"betterComments.tags": [
  { "tag": "!",     "color": "#8F3D2D", "strikethrough": false, "underline": false, "backgroundColor": "transparent", "bold": true,  "italic": false },
  { "tag": "?",     "color": "#4A6A8A", "strikethrough": false, "underline": false, "backgroundColor": "transparent", "bold": false, "italic": true  },
  { "tag": "TODO",  "color": "#3A3E43", "strikethrough": false, "underline": false, "backgroundColor": "transparent", "bold": true,  "italic": false },
  { "tag": "*",     "color": "#5A5F66", "strikethrough": false, "underline": false, "backgroundColor": "transparent", "bold": false, "italic": true  },
  { "tag": "//",    "color": "#626E74", "strikethrough": true,  "underline": false, "backgroundColor": "transparent", "bold": false, "italic": false }
]
```

| 标签 | 语义 | 颜色 | 字体 |
|---|---|---|---|
| `!` | 警示 | 朱砂红 | 粗体 |
| `?` | 疑问 | 远水蓝 | 斜体 |
| `TODO` | 待办 | 重墨 | 粗体 |
| `*` | 强调 | 淡墨 | 斜体 |
| `//` | 弃用 | 水汽灰青 | 删除线 |

### Todo Tree / TODO Highlight

注释中的 `TODO` / `FIXME` / `XXX` / `HACK` / `NOTE` 关键字已通过 tokenColors 着色：`TODO` 朱砂粗体、`FIXME`/`XXX` 重墨、`HACK`/`NOTE` 远水蓝斜体。
