# 水墨 Theme (Shuimo Theme)

几抹淡墨涵万象，一帧素宣蕴乾坤。

一款精心打磨的高雅代码配色主题扩展。

## 包含主题

1. **水墨·浅 (Shuimo Light)**：素宣底色（#F6F5E1）、浓淡墨色、朱砂红关键字与指示条、黛蓝常量与字符串、苍翠绿注释。
2. **水墨·深 (Shuimo Dark)**：玄墨深底（#1C1B1A）、月魄白前景色、珊瑚红关键字、霁蓝字符串、松针绿注释与琥珀金。
3. **水墨 - IntelliJ New UI**：基于 VS Code 官方 Dark 规范与 JetBrains 官方最新 **New UI (Dark)** 配色体系精炼而成（#1E1F22 标志性底色、#BCBEC4 原生白灰主体、#3574F0 品牌蓝指示条、#CF8E6D 纯平暖橙关键字、#56A8F5 天蓝函数与 #6AAB73 翠绿字符串）。

## 使用

1. 在扩展市场搜索并安装 `水墨 Theme`。
2. 按快捷键 `Ctrl+Shift+P`（Mac 为 `Cmd+Shift+P`），输入 `Preferences: Color Theme`。
3. 选择对应主题（`水墨·浅`、`水墨·深` 或 `水墨 - IntelliJ New UI`）。
